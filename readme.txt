Organise documents into groups with drag-and-drop upload and display them anywhere via shortcode.

== Description ==

Document Manager lets WordPress admins create document groups, bulk-upload files via drag-and-drop,
rename and reorder files, and embed a download list on any page using a simple shortcode.

**Features:**

* Unlimited document groups
* Drag-and-drop bulk file upload
* Browse button and WordPress Media Library integration
* Inline file rename
* Drag-to-reorder files within a group
* One-click shortcode copy
* Clean, responsive frontend document list
* File type icons and size display

== Installation ==

1. Upload the `Document Manager` folder to `/wp-content/plugins/`.
2. Activate the plugin through the **Plugins** menu.
3. Go to **Doc Manager** in the admin sidebar to create groups and upload files.
4. Copy a group's shortcode and paste it into any page or post.

== Usage ==

Use `[doc_group id=X]` where X is the group ID shown in the admin panel.
